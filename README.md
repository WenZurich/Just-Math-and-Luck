# 每日數學選股

美股＋台股依動能／相對強度／均線／量比的數學篩選儀表板。

**網站：** https://WenZurich.github.io/Just-Math-and-Luck-/

> 內容為公開行情篩選候選，**不是投資建議**，亦不保證獲利。

## 更新資料

1. 更新 `public/data/latest.json`
2. 本地 `npm run build`，把 `dist/` 內容覆寫到 `docs/`
3. 推到 `main`（目前以 `docs/` 做 GitHub Pages）

來源碼在 `src/`；每日選股 bot 也可直接覆寫 `docs/data/latest.json` 後 push。
